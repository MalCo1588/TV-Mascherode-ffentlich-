# TVM Ü32 Trainer – Downloads

Android-App der Altherren Ü32 des TV Mascherode: Trainingsplaner mit 200 Übungen, Vorbereitungs-Einheiten, Teamliste und Laufchallenge.

## Installieren
1. Rechts unter **Releases** die neueste Version öffnen.
2. Die Datei **TVM-Ue32-Trainer-vX.Y.apk** auf dem Android-Handy herunterladen und antippen.
3. Beim ersten Mal erlauben, dass der Browser „unbekannte Apps installieren“ darf.

## Aktualisieren
Die App prüft beim Start selbst, ob es eine neue Version gibt, und zeigt dann „Herunterladen“ an.
Die neue Datei antippen und **Aktualisieren** wählen. Einstellungen und Daten bleiben erhalten.

Nur für den internen Gebrauch der Altherren Ü32.
