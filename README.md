# TVM Ü32 Trainer – Downloads

Android-App der Altherren Ü32 des TV Mascherode: Trainingsplaner mit 200 Übungen, Vorbereitungs-Einheiten, Teamliste und Laufchallenge.

## Installieren
**[⬇ Aktuelle App herunterladen](https://raw.githubusercontent.com/MalCo1588/tv-mascherode-ffentlich-/main/apk/TVM-Ue32-Trainer-aktuell.apk)**

1. Den Link oben auf dem Android-Handy öffnen und die APK herunterladen.
2. Die Datei antippen. Beim ersten Mal erlauben, dass der Browser „unbekannte Apps installieren“ darf.
3. In der App unter **Team → Synchronisation** Link und Team-PIN eintragen (gibt es beim Trainer). Dann kommen Teamliste und Laufchallenge automatisch.

## Aktualisieren
Ab Version 2.6 prüft die App beim Start selbst, ob es eine neue Version gibt, und zeigt dann „Herunterladen“ an.
Die neue Datei antippen und **Aktualisieren** wählen. Einstellungen und Daten bleiben erhalten.

Ältere Versionen liegen im Ordner `apk/`. Nur für den internen Gebrauch der Altherren Ü32.
